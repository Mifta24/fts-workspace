# Fonts

`plus-jakarta-sans-latin.woff2` is Plus Jakarta Sans (variable, weights 200 to 800), Latin subset,
downloaded from Google Fonts (version 12) on 2026-11-02. Licence: SIL Open Font License 1.1
(https://openfontlicense.org). It is self-hosted so that builds and the dev server do not depend on
reaching fonts.googleapis.com. Characters outside the Latin subset (and Japanese) use the system
fallback fonts listed in `globals.css`.
